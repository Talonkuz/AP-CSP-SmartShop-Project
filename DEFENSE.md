# Project delivery and oral defense

## What to submit

1. **smartshop.py** — Python program with all required features, written by you.
2. **DOCUMENTATION.md** or PDF — user problem, project goal, algorithms, data structures, function overview, known limitations, and your personal contribution.
3. **TESTING report** — 15+ tests: inputs, expected results, actual results, pass/fail.
4. **Screen recording (1–2 minutes)** — demonstrate catalog, search, cart, recommendations, checkout and history.
5. **Live demonstration & oral defense**.

## 15 defense questions

1. What real problem does SmartShop solve?
2. Why do you use a list for the catalog?
3. How is a dictionary different from a list?
4. Why does the menu need a `while` loop?
5. When do we use `for` versus `while`?
6. What is the role of `append()`?
7. What is the difference between `return` and `print()`?
8. Why does a function need parameters?
9. How do you check stock when the same item is already in a cart?
10. How does your discount logic work at 20 000, 50 000 and 100 000 KZT?
11. Why is your recommendation algorithm rule-based rather than ML?
12. Why shouldn't stock change before checkout succeeds?
13. How do you prevent crashes on invalid input?
14. Show a real example of sequencing, selection and iteration in your code.
15. What feature would you add next and why?

## Required live tasks (teacher may choose one)

- Add a new catalog product and show it in search.
- Explain one branch of the recommendation logic.
- Correct a bug in quantity validation.
- Explain why a cancelled order leaves inventory unchanged.
- Change one discount threshold and predict which tests must change.

**Remember:** You must be able to explain every part of the code you submit.
