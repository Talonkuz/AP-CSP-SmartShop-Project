# Eight-lesson classroom plan (40 minutes each)

| Lesson | Focus | Student deliverable |
|---:|---|---|
| 1 | Data, product dictionaries, menu loop | 10 products + menu |
| 2 | Catalog rendering, case-insensitive search | Show/search work |
| 3 | Find product, add/remove cart, quantity rules | Safe cart |
| 4 | Total, discounts, promo and delivery | Correct invoice arithmetic |
| 5 | Budget/category recommendation, sorted output | Recommendation function |
| 6 | Simulated checkout, receipt, history | End-to-end purchase |
| 7 | Invalid inputs, boundaries, test documentation | 15+ tests |
| 8 | Optional enhancement, demonstration, oral defense | Final submission |

## Suggested 40-minute rhythm

- **5 min:** Teacher shows one problem and expected result.
- **10 min:** Explain a single concept with a tiny Python example.
- **20 min:** Students implement and test that step.
- **5 min:** Quick check: predict output, demonstrate code, reflect on a bug.

## Differentiation

- **Beginning students:** Start from `starter.py`; focus on core logic, with helper functions allowed.
- **Confident students:** Implement their own validation helpers, better receipts, comprehensive tests.
- **Advanced students:** See `ADVANCED.md` once the required features pass.

Do not provide a complete solution before students try the TODOs.
